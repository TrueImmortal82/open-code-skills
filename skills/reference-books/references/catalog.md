## Keeping the catalog fresh

This catalog is the lookup table an agent reads before touching the drive.
Maintenance duty: when `node scripts/fetch-book.mjs --list` returns a file
that is not in this table, add a row here (topic, language, one-line covers,
use-when) and update the SKILL.md topic→book map, then commit. Treat a
`(N)`-suffixed duplicate as the same book as its base name.
